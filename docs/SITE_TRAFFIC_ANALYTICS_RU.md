# Аналитика посещений сайтов — AI Tools Ecosystem

Статус: **PREPARED / NOT_ACTIVATED**. Этот скрипт **не устанавливает новый счётчик**, не создаёт cookies и не отправляет данные посетителей третьим сторонам. Он читает **уже собираемую** хостингом here.now агрегированную статистику. GitHub `main`, сайт и TOKEN HOLD остаются неизменными.

## Две разные площадки

1. **AI Tools Ecosystem**: статический исходник в этом репозитории, подготовленный для **here.now**. Факт рабочего деплоя, URL и тариф нужно подтвердить отдельно. На here.now статистика собирается хостингом на уровне запросов, если сайт размещён.
2. **Local Media AI Community**: отдельный опубликованный сайт `https://local-media-ai-community.cheekysloth259.chatgpt.site/` на **ChatGPT Sites**. Отчёт here.now **не охватывает его**. Для этого сайта требуется отдельная аналитика через настройки/код ChatGPT Sites, разрабатываемая в Work с проверкой безопасности и политики конфиденциальности.

## Какие показатели доступны здесь

- Просмотры страниц и приблизительные уникальные посетители.
- **Страны** с ранжированием по просмотрам и долями.
- **Источники переходов** (referrers): прямые ссылки, поисковики, внешние площадки.
- Популярные страницы, известные поисковые/ИИ-роботы (отдельно).
- Периоды `24h`, `7d`, `30d`, `90d`, `all`.

Страны — приблизительное определение по сетевым сигналам, не персональные сведения. Прямой переход не доказывает, что пользователь вводил адрес вручную: referrer может быть недоступен.

## Как получить отчёт (Windows / Python 3.11+)

Для here.now требуются владение опубликованным сайтом и API-ключ владельца; актуальные тарифные ограничения необходимо уточнять по официальной документации (см. https://here.now/docs#analytics). Не создавайте ключ только для тестов; используйте существующий защищённый ключ. Никогда не публикуйте его в GitHub, логах, issue, браузерном JS, CI-артефактах или сообщениях ChatGPT.

Задайте в текущей сессии окружения **`HERENOW_API_KEY`** (или `HERENOW_ANALYTICS_KEY`) через доверенный секретный менеджер/секрет окружения; дополнительно задайте `HERENOW_SITE_SLUG`. Не вводите ключ как параметр командной строки.

```powershell
python -m unittest discover -s tests -p "test_report_herenow_traffic.py" -v
python scripts/report_herenow_traffic.py --slug YOUR-PUBLISHED-SITE-SLUG --range 30d
```

Скрипт только читает `GET /api/v1/publishes/:slug/analytics`, выводит локальную таблицу; сам ничего не публикует. В случае отсутствия доступа показывает безопасную ошибку, не печатает секрет. **Пока ключ/slug не подключены, фактические числа посещений неизвестны**.

### Повторная проверка

После подключения настоящего опубликованного сайта и разрешённого доступа выполнить чтение периода 30d, затем 7d и 24h, проверить, что роботы отделены от людей. Публичный сайт не должен показывать административные данные.

Документация: https://here.now/docs#analytics


## Раздельная аналитика двух площадок (22.11.2026)

### here.now — AI Tools Ecosystem

Используйте `scripts/report_herenow_traffic.py`, если сайт реально опубликован и есть разрешённый доступ владельца к аналитике API. На дату проверки URL опубликованного экземпляра и данные владельца в этом чате **не подтверждены**. Код не устанавливает трекер на сайт и ничего не публикует. Доступность API и тариф проверяйте по текущей официальной документации, а не по старой записи о платном плане.

### ChatGPT Sites — Local Media AI

Откройте `https://chatgpt.com/sites` → ваш сайт → `Analytics`. Для этой площадки используйте только доступные в интерфейсе агрегированные просмотры и уникальных посетителей, **не приписывая** ей географию, referrers или детальные страницы, пока платформа явно не предоставляет эти показатели. Это отдельный сайт и его статистика **не объединяется с here.now в одну аудиторию**.

При наличии данных Sites занесите агрегаты только во временный **локальный** JSON-файл, не коммитьте его:

```json
{"period": "7d", "page_views": 123, "unique_visitors": 45}
```

Числа 123 и 45 — примеры формата, **не реальная статистика**.

Для общего отчёта требуется JSON от here.now API, сохранённый локально и **не в GitHub**. Запуск:

```powershell
python -m unittest discover -s tests -p "test_report_two_sites_traffic.py" -v
python scripts/report_two_sites_traffic.py --here-now-json C:\\private\\herenow-7d.json --sites-json C:\\private\\chatgpt-sites-7d.json --site-slug YOUR-PUBLISHED-SITE-SLUG --range 7d
```

Если доступна только одна площадка, пропустите отсутствующий аргумент. Отчёт пометит её показатели как неизвестные, **не как нулевые**. Для сравнения всегда используйте один временной интервал. Не загружайте API-ключи, скриншоты со сведениями об аккаунте, индивидуальные IP или реальную статистику в открытый GitHub.
