## Что публикуем

AI Tools Ecosystem — единый информационный сайт **без криптовалютного предложения**:

1. **Local Media AI** — есть отдельный информационный сайт; Windows/NVIDIA, установщик и полный выпуск Community 1.0 остаются на тестировании / HOLD.
2. **CVLM Platform** — концепция и проектирование инструментов для разработки и QA ПО. Публичный программный релиз не заявляется.
3. **LocalAIDevManager** — концепция и проектирование управления локальными ИИ-моделями и агентами. Публичный программный релиз не заявляется.

На сайте 12 черновых языковых главных страниц; детальные страницы CVLM/LocalAIDevManager подготовлены на русском и английском. Переводы требуют проверки носителем языка перед поисковой индексацией. Нельзя выдавать информационный сайт Local Media AI за утверждённый установщик.

## Безопасная публикация — только с защищённым подтверждением

1. В GitHub Actions открыть [Deploy static website to here.now (manual)](https://github.com/my-project-01012026/ai-tools-ecosystem/actions/workflows/deploy-herenow.yml).
2. Выбрать ветку `main` и указать **только** `quiet-flint-6kde` в `site_slug`; это значение уже предусмотрено по умолчанию.
3. Workflow должен подтвердить защищённую ветку, запустить offline-тесты и проверить контрольные хэши **до обращения к продакшен-секрету**.
4. Задание `publish` использует защищённое окружение `here-now-production`. **Нельзя обходить обязательное подтверждение reviewer, менять защищённые правила ради публикации либо копировать API-ключ в чат, файлы или логи.**
5. Рабочий ключ `HERENOW_API_KEY` хранится только как GitHub Environment secret. Обновление сверяет `currentVersionId` и передаёт `baseVersionId`; конфликт изменения сайта приводит к блокировке вместо перезаписи.
6. После публикации workflow выполняет `scripts/audit_live_site.py` (33 файла, SHA-256, реальные `/section/`-адреса, HTTPS, внешняя ссылка Local Media AI, предупреждения) и `scripts/check_retired_routes.py` (старые URL → 404, новые страницы → 200). При любом несоответствии workflow завершится ошибкой.

**Критично:** технический шаг публикации может выполниться до последующего FAIL проверки сайта. Поэтому нельзя делать вывод «новый сайт принят», ориентируясь только на факт успешной загрузки файлов. Не допускать рассылку инвесторам до полной независимой проверки действующих страниц.

## Ограничения и поиск инвесторов

- Метаданные `noindex,nofollow` и `robots.txt: Disallow: /` сохранены до live-аудита и проверки локализаций. Ссылки по прямому URL доступны, но органическая поисковая индексация пока запрещена.
- Сайт не собирает контакты посетителей и не отправляет email. Сбор статистики посещаемости и подключение Google Analytics/других счётчиков — отдельный согласованный этап.
- Любые адреса для инвесторов/партнёров публиковать только после подтверждения актуальной версии, надёжности внешней ссылки и фактических статусов продуктов.
- Текущий монитор финансирования и отдельный Funding Scout не дают права на автоматическую массовую email-рассылку.
